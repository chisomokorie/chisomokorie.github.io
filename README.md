# Chisom Okorie Portfolio

Personal portfolio: business analysis, operations, program coordination and AI.

Live at https://chisomokorie.github.io

## Files

- `index.html`: the whole site
- `Chisom_Okorie_Resume.pdf`: the public resume (no phone number), used by every "Download resume" button
- `assets/chisom-okorie.jpg`: profile photo
- `assets/linkedin-banner.jpg`: the LinkedIn banner, also used as the link preview image
- `assets/favicon.svg`: browser tab icon

## Handy links

- Recruiter mode opens straight away at https://chisomokorie.github.io/#recruiter

## Updating the resume

Replace `Chisom_Okorie_Resume.pdf` with a new file of the same name. Every download button picks it up.
